# Tableau

Simpan workbook dashboard (`.twb` atau `.twbx`) di folder ini.

Sumber data asli berada di `data/processed/`:

- `nusantaratv_analytics.csv`
- `nusantaratv_keywords.csv`

Setelah DAG analytics selesai, refresh kedua sumber melalui menu Data di Tableau.
Untuk tetap membaca hasil ekspor terbaru, gunakan CSV asli; packaged workbook
bisa menyimpan salinan data terpisah.
